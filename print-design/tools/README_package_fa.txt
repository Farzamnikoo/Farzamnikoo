پیش از استفاده از قالب Word
────────────────────────────────────────

۱. قلم‌های پوشه 05_Fonts را روی رایانه نصب کنید (روی هر فایل TTF راست‌کلیک ← Install).
   بدون وزیرمتن، Word قلم دیگری جایگزین می‌کند و سربرگ به هم می‌ریزد.
۲. روی فایل .dotx دوبار کلیک کنید؛ Word یک سند جدید بر پایه قالب باز می‌کند.
۳. صفحه اول سربرگ کامل دارد و صفحه‌های بعد خودکار سربرگ صفحه دوم (نشان کوچک و «صفحه ... از ...»).
۴. شماره، تاریخ و پیوست: روی سربرگ دوبار کلیک کنید و بعد از هر عنوان تایپ کنید.
۵. «بسمه تعالی» طبق تصمیم شما در بدنه قالب به‌صورت متن آمده و قابل حذف است.
۶. اگر نامه را برای کسی می‌فرستید که وزیرمتن ندارد، PDF بفرستید؛
   یا در Word: File ← Options ← Save ← Embed fonts in the file.

────────────────────────────────────────
نکته‌های چاپ
────────────────────────────────────────

• فایل‌های print_PDFX1a با پروفایل Coated FOGRA39 به CMYK تبدیل شده‌اند
  (پروفایل از داده‌های مشخصه‌یابی FOGRA39 ساخته شده است).
  پیش از چاپ، فایل را به preflight چاپخانه بدهید و اگر چاپخانه پروفایل دیگری می‌خواهد، اعلام کند.
• سربرگ برای چاپ دو رنگ (سرمه‌ای + طلایی) طراحی شده است. فایل تحویلی چهاررنگ است؛
  برای چاپ دو رنگ، چاپخانه دو رنگ را به دو رنگ اختصاصی (Pantone) تبدیل می‌کند:
  سرمه‌ای نزدیک Pantone 2767 C یا 289 C، طلایی از روی کتاب رنگ چاپخانه.
• بروشور: تای غلتان راست‌به‌چپ. روی برگه بیرونی از چپ به راست: جلد (۱۰۰)، پشت جلد (۱۰۰)،
  لت تاشونده (۹۷ میلی‌متر). داخل از چپ به راست: پنل ۶ (۹۷)، پنل ۵، پنل ۴.
  علائم تا بیرون از کادر برش، خط‌چین‌اند.
• کاتالوگ: منگنه از وسط، راست‌به‌چپ؛ صفحه‌های زوج سمت راست و فرد سمت چپ باز می‌شوند.
  زمینه کرم صفحه‌های داخلی در فایل چاپی به‌صورت تنت بسیار روشن هست؛ اگر کاغذ کرم انتخاب کنید،
  بهتر است زمینه حذف شود (یک تغییر در فایل منبع).
