## سیستم کاتالوگ به‌طور خلاصه

- A4، ۱۶ صفحه، منگنه وسط، راست‌به‌چپ (عطف در لبه راست جلد؛ صفحه‌های زوج راست، فرد چپ).
- ستون متن ۱۷۵ × ۲۵۸ میلی‌متر؛ ۱۲ ستون ۱۰ میلی‌متری با ناودان ۵؛ خط پایه ۶ میلی‌متر.
- وزیرمتن در پنج سطح: ۳۴ / ۲۱ / ۱۱٫۵ / ۹٫۵ / ۷٫۸ پوینت؛ Inter فقط برای لاتین.
- هر بخش: عنوان ۲۱ پوینت + خط طلایی ۰٫۷۵ پوینت. شماره صفحه پایین، سمت بیرونی.
- آیکون‌های سه ابزار: یک خانواده خطی با هندسه گرد و یک عنصر طلایی (`src/icons.mjs`).
- الگوی زنجیره (سه حلقه بافته) فقط روی جلد و پشت جلد، هم‌خانوادهٔ رنگ زمینه.

## ابزارها

| کار | ابزار | دلیل |
|---|---|---|
| صفحه‌آرایی | HTML/CSS با ابعاد میلی‌متری | راست‌به‌چپ و اتصال حروف فارسی بی‌نقص؛ یک منبع برای چاپ، PDF و وب |
| فونت | وزیرمتن و Inter (مجوز آزاد OFL) | فایل‌ها در `brand/fonts/` |
| خروجی PDF | Chromium از طریق Playwright | PDF برداری با فونت جاسازی‌شده، بدون تصویر رستری |
| نشان و الگو | skia-pathops (عملیات بولی روی منحنی‌ها) | گره حلقه‌ها به شکل هندسه واقعی، نه خط هم‌رنگ زمینه |
| تبدیل چاپی | Ghostscript | CMYK و PDF/X-1a در مرحله ۵ |
| قالب Word | python-docx | `.dotx` با همان حاشیه‌ها و فونت، در مرحله ۵ |

## ساختار

```
data/master.mjs        داده‌های پایه مشترک (بخش صفر سند): تنها جای داده‌های ثبتی و تماس

brand/qr-tafund.svg    کد QR برداری به tafund.ir
src/letterhead.*       سربرگ و سه گزینه چیدمان
src/compare.mjs        برگه مقایسه سربرگ
src/catalog.*          صفحه‌های کاتالوگ و سیستم صفحه‌بندی
src/catalog-system.*   برگه سیستم A3
src/icons.mjs          آیکون‌های سه ابزار و چهار ارزش، علامت‌های فهرست

tools/logo.py          ساخت فایل‌های برداری نشان
tools/pattern.py       ساخت الگوی زنجیره
review/                صفحه مرور و تصمیم
```

## ساخت

```bash
npm install
npx playwright install chromium   # فقط بار اول
pip install skia-pathops          # فقط برای ساخت دوباره نشان و الگو
python3 tools/logo.py && (cd tools && python3 pattern.py)
npm run build                     # یا: node tools/build.mjs catalog16
```

## نشان

نشان گزینهٔ ۳ «زنجیرهٔ پیوند» است. در سند تصمیم، گره دو حلقه با یک خط پهن هم‌رنگ زمینه ساخته شده که فقط روی زمینه‌ای با همان رنگ درست درمی‌آید. `tools/logo.py` همان هندسه را به شکل‌های بسته تبدیل می‌کند تا نشان روی هر زمینه‌ای و در PDF/X بدون شفافیت درست چاپ شود. تا انتخاب واریاسیون نهایی، طبق توصیه سند از ۳-الف (با قاب) و ۳-ج (بدون قاب، برای اسناد چاپی) استفاده شده است.

رنگ‌های نشان با پالت چاپی هماهنگ شده‌اند: سرمه‌ای ‎#0F2547‎ (ابتدای بازه مصوب، تقریباً همان ‎#0E1F3C‎ سند نشان)، طلایی ‎#C9A227‎ و طلایی روشن ‎#DFC069‎.
