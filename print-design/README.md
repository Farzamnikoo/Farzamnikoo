# اقلام چاپی صندوق پژوهش و فناوری توسعه و آینده

سربرگ رسمی، کاتالوگ شرکتی ۱۶ صفحه‌ای و بروشور سه‌لت، بر پایه «بسته محتوایی و پرامپت طراحی اقلام چاپی» (نسخه ۱، مهر ۱۴۰۵).

## وضعیت گردش کار

| مرحله | موضوع | وضعیت |
|---|---|---|
| ۱ | سربرگ: سه گزینه چیدمان هدر و فوتر | **آماده، در انتظار انتخاب کارفرما** |
| ۲ | شبکه و صفحه‌بندی کاتالوگ روی سه صفحه نمونه | پس از انتخاب سربرگ |
| ۳ | کاتالوگ کامل ۱۶ صفحه | پس از تأیید مرحله ۲ |
| ۴ | بروشور سه‌لت | پس از مرحله ۳ |
| ۵ | بازبینی نهایی و خروجی چاپی (PDF/X-1a، قالب Word) | پایان کار |

صفحه مرور و انتخاب گزینه‌ها: https://claude.ai/artifact/4w8uKxCeg1z4EUunUq5bP9

## خروجی‌های مرحله ۱ (`dist/01-letterhead-options/`)

| فایل | شرح |
|---|---|
| `compare_LH-01_options_A3.pdf` | برگه مقایسه A3 افقی، سه صفحه: نمای کامل، جزئیات ۱:۱، آزمون سیاه‌وسفید |
| `LH-01_option-A.pdf` تا `C` | هر گزینه در اندازه واقعی A4، برای چاپ آزمایشی روی چاپگر اداری |
| `png/` | تصویر هر گزینه، با و بدون راهنمای ناحیه امن متن، و برش‌های هدر و فوتر با وضوح بالا |

## ابزارها

| کار | ابزار | دلیل |
|---|---|---|
| صفحه‌آرایی | HTML/CSS با ابعاد میلی‌متری | راست‌به‌چپ و اتصال حروف فارسی بی‌نقص؛ یک منبع برای چاپ، PDF و وب |
| فونت | وزیرمتن (Regular، Medium، Bold) و Inter برای لاتین | هر دو با مجوز آزاد OFL؛ فایل‌ها در `brand/fonts/` |
| خروجی PDF | Chromium از طریق Playwright | PDF برداری با فونت جاسازی‌شده |
| تبدیل چاپی | Ghostscript | تبدیل به CMYK و PDF/X-1a در مرحله ۵ |
| قالب Word | python-docx | ساخت `.dotx` با همان حاشیه‌ها و فونت |

## ساختار

```
data/master.mjs      داده‌های پایه مشترک (بخش صفر سند): تنها جای داده‌های ثبتی و تماس
brand/tokens.css     رنگ‌ها و فونت‌ها
brand/logo-mark*.svg نشان (فعلاً موقت؛ با فایل مصوب جایگزین شود)
src/letterhead.*     سربرگ و سه گزینه چیدمان
src/compare.mjs      برگه مقایسه A3
tools/build.mjs      ساخت همه خروجی‌ها
review/              صفحه مرور و انتخاب
```

## ساخت

```bash
npm install
npx playwright install chromium   # فقط بار اول
npm run build
```

## نشان موقت

فایل نشان مصوب در اختیار نبود. نشان فعلی (سه طاق تو در تو) فقط جای خالی را پر می‌کند تا چیدمان‌ها قابل داوری باشند. با قرار دادن فایل SVG مصوب به‌جای `brand/logo-mark.svg` (نسخه رنگی روی مربع)، `logo-mark-line.svg` (خطی برای زمینه روشن) و `logo-mark-reverse.svg` (برای زمینه سرمه‌ای) و اجرای دوباره ساخت، همه اقلام به‌روز می‌شوند.
