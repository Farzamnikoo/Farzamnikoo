## ویرایش ۴: ابزارهای مبتنی بر مطالبات، مزایای مالیاتی و عاملیت

به درخواست کارفرما: صندوق «خرید دین» و «فاکتورینگ» هم دارد؛ «عاملیت» معرفی شود؛ مزایای مالیاتی بازتر شود.

- **تسهیلات (۹):** «خرید دین» و «فاکتورینگ» با شرح کوتاه به انواع تسهیلات اضافه شد. در بروشور هم در پنل تسهیلات آمد.
- **مزایای مالیاتی (۱۱، صفحه تازه):** مبنای قانونی (ماده ۱۱ قانون جهش تولید دانش‌بنیان)، سه گروه بهره‌مند، نقش صندوق در چهار گام و قید «تابع شرایط قانون و تأیید سازمان امور مالیاتی». عمداً بدون درصد و سقف؛ کادر مزیت مالیاتی صفحه ۱۰ به آن ارجاع می‌دهد.
- **عاملیت و اداره وجوه (۱۴، صفحه تازه):** صاحبان منابع، چرخه پنج‌گامی (طراحی برنامه، فراخوان و ارزیابی، قرارداد و تخصیص، پایش و وصول، گزارش‌دهی)، ابزارها و مزیت برای صاحب منابع. در بروشور، کادر کوتاه «عاملیت و اداره وجوه» در لت.
- **ماندن در ۱۶ صفحه:** «رویکرد ارزیابی» (صفحه ۱۲ ویرایش ۳) در صفحه فرآیند ادغام شد (نقل‌قول و بند دو محور بالای صفحه)، و «مسیرهای همکاری» و «تماس با ما» یک صفحه شدند.
- متن‌های تازه در `data/*.mjs` با `[ویرایش ۴]` علامت خورده‌اند و باید پیش از چاپ به تأیید واحدهای حقوقی و مالیاتی صندوق برسند.

ترتیب فعلی: ۱ جلد · ۲ پیام مدیرعامل · ۳ صندوق در یک نگاه · ۴ چشم‌انداز، مأموریت، ارزش‌ها · ۵ چارچوب قانونی و نظارتی · ۶ مزیت‌های همکاری · ۷ سه ابزار، یک مسیر · ۸ ضمانت‌نامه · ۹ تسهیلات · ۱۰ مشارکت و سرمایه‌گذاری · ۱۱ مزایای مالیاتی · ۱۲ خدمات تخصصی · ۱۳ فرآیند بررسی درخواست · ۱۴ عاملیت و اداره وجوه · ۱۵ مسیرهای همکاری و تماس · ۱۶ پشت جلد.

## ویرایش ۳: ساختار و متن کاتالوگ

به درخواست کارفرما (۶ مهر ۱۴۰۵): صفحه ۱۰ کامل شود، صفحه‌های ۱۲ و ۱۳ حذف شوند، و متن‌ها برای یک نهاد مالی بزرگ بازبینی شوند.

- **حذف:** «متقاضیان واجد شرایط» و «ارکان و حاکمیت صندوق». با حذف آن‌ها فهرست TODO کاتالوگ دیگر معرفی هیئت‌مدیره را ندارد.
- **ماندن در ۱۶ صفحه:** منگنه وسط فقط ۸، ۱۲ یا ۱۶ صفحه می‌پذیرد؛ ۱۴ صفحه چاپ‌شدنی نیست. دو صفحه تازه جای صفحه‌های حذف‌شده را گرفت:
  - ۶ «مزیت‌های همکاری با صندوق»: شش مزیت با آیکون، هر کدام بازگویی واقعیتی از همین سند.
  - ۱۲ «رویکرد ارزیابی»: نقل‌قول پیام مدیرعامل، دو محور ارزیابی و تصمیم در کمیته؛ روبه‌روی «فرآیند بررسی درخواست» (۱۳).
- **خدمات تخصصی (۱۱):** مقدمه، تصویرسازی خطی (`illos` در `src/icons.mjs`) و سه محور برای هر خدمت. سه محور متن تازه است و باید با دامنه واقعی خدمت تطبیق داده شود.
- **ویرایش متن:** «پیام مدیرعامل»، «چارچوب قانونی و نظارتی»، حذف ویرگول پیش از «و»، نام کامل صندوق در بروشور. هر متن تازه یا ویرایش‌شده در `data/*.mjs` با `[ویرایش ۳]` علامت خورده و فهرست کامل تغییرات در صفحه مرور آمده است.

(ترتیب ویرایش ۳ در ویرایش ۴ تغییر کرد؛ ترتیب فعلی در بخش بالا.)

## ویرایش ۲: زبان بصری نهاد مالی

به درخواست کارفرما («متن‌ها جاستیفای شود؛ طراحی شیک‌تر، در سطح یک نهاد مالی»):

- **تمام‌تراز:** همه بندهای متن در کاتالوگ و بروشور `text-align: justify` با سطر آخر راست‌چین. فهرست‌ها و ستون‌های باریک‌تر از حدود ۶۰ میلی‌متر راست‌چین می‌مانند، چون تمام‌تراز در آن‌ها فاصله‌های بزرگ بین کلمه‌ها می‌سازد. بدنه نامه در قالب‌های Word هم تمام‌تراز است (`jc=both`).
- **تایپوگرافی:** عنوان بخش وزیرمتن Light (۳۰۰) در ۲۷ پوینت با خط کوتاه طلایی؛ متن مقدمه هر بخش ۱۱٫۵ پوینت Light سرمه‌ای؛ بدنه ۱۰ پوینت. اعداد درشت (آمار، شماره گام‌ها) ExtraLight. قلم‌های Light، ExtraLight و SemiBold به `brand/fonts/` اضافه شدند.
- **کادرها:** سطح‌های خاکستری حذف شدند؛ کادرها کاغذ سفید با خط طلایی بالا، جدول‌ها و فهرست‌ها با خط مویی ۰٫۳۵ پوینت.
- **ترکیب‌بندی:** صفحه ۳ با سطح سرمه‌ای تا لبه پایین، صفحه ۴ با بیانیه‌های درشت، صفحه ۱۰ شبکه ۲ × ۲، صفحه ۱۴ سه ردیف تمام‌عرض، صفحه ۱۵ با امضای نشان و نام کامل.
- **پانویس جاری:** نام کامل صندوق سمت عطف و شماره صفحه سمت بیرون، روی خط مویی.
- **جلدها:** زنجیرهٔ حکاکی‌شده (`tools/engrave.py`): هر حلقه با هشت خط موازی هم‌مرکز و همان بافت رو و زیر، به شیوه اوراق بهادار. خط‌ها سطح پر هستند (نه stroke) و کمترین ضخامتشان روی جلد کاتالوگ حدود ۰٫۲۷ میلی‌متر است.

- داخل: سه ابزار در سه پنل و نوار چهارگامی فرآیند تمام‌عرض با پیکان‌های راست‌به‌چپ. خط پایه ۵٫۵ میلی‌متر.

## خروجی چاپی

- `tools/print.mjs` هر قلم را با نشت ۳ میلی‌متر و حاشیه ۱۰ میلی‌متری علائم می‌سازد و با Ghostscript به PDF/X-1a:2001 (PDF 1.3، CMYK، بدون شفافیت، فونت جاسازی‌شده، Output Intent از نوع FOGRA39) تبدیل می‌کند. `tools/boxes.py` جعبه‌های TrimBox و BleedBox را می‌نویسد.

- سربرگ برای چاپ دو رنگ طراحی شده؛ فایل تحویلی چهاررنگ است و تبدیل به دو رنگ اختصاصی با چاپخانه است.

- A4، ۱۶ صفحه، منگنه وسط، راست‌به‌چپ (عطف در لبه راست جلد؛ صفحه‌های زوج راست، فرد چپ).
- ستون متن ۱۷۵ × ۲۵۸ میلی‌متر؛ ۱۲ ستون ۱۰ میلی‌متری با ناودان ۵؛ خط پایه ۶ میلی‌متر.

## ساخت

```bash
npm install
npx playwright install chromium   # فقط بار اول
pip install skia-pathops pikepdf  # نشان و الگو؛ جعبه‌های PDF چاپی
python3 tools/logo.py && (cd tools && python3 pattern.py && python3 engrave.py)
npm run build                     # یا: node tools/build.mjs catalog16 | brochure | lh-final
npm run word                      # قالب‌های Word
npm run logo                      # خروجی نشان
npm run print                     # PDF/X-1a (نیازمند Ghostscript)
npm run package                   # بسته تحویل و ZIP
```

## نشان

نشان گزینهٔ ۳ «زنجیرهٔ پیوند» است. در سند تصمیم، گره دو حلقه با یک خط پهن هم‌رنگ زمینه ساخته شده که فقط روی زمینه‌ای با همان رنگ درست درمی‌آید. `tools/logo.py` همان هندسه را به شکل‌های بسته تبدیل می‌کند تا نشان روی هر زمینه‌ای و در PDF/X بدون شفافیت درست چاپ شود. واریاسیون ۳-الف (پایه، با گره واقعی) انتخاب شده است.

رنگ‌های نشان با پالت چاپی هماهنگ شده‌اند: سرمه‌ای ‎#0F2547‎ (ابتدای بازه مصوب، تقریباً همان ‎#0E1F3C‎ سند نشان)، طلایی ‎#C9A227‎ و طلایی روشن ‎#DFC069‎.
